## 2. Project Story (Markdown Copy-Paste for Devpost Description)

### Inspiration & Problem Statement
Complex medical discharge instructions, student financial aid agreements, government benefits forms, and technical documentation create severe cognitive, visual, and screen-reader barriers for neurodivergent readers, dyslexic users, low-vision individuals, and non-native speakers. At the same time, over 94% of public web pages fail **WCAG 2.2 Level AA** structural, contrast, and ARIA semantic requirements.

### What It Does — 4 Real-Time Cognitive & Sensory Access Modes
**AccessLens AI** is a zero-install interactive Web Application and Python CLI WCAG 2.2 AA Auditor (`wcag_auditor.py`) that accepts any complex article, medical/legal/financial text, or raw HTML snippet (including 4 built-in real-world presets) and transforms it instantaneously into **4 Cognitive & Sensory Access Modes**:

1. **Plain-Language Reading Level (5th-Grade / CEFR B1 Executive Summary + Action Checklist):**
   - Reduces Flesch-Kincaid reading grade complexity from **Grade 16.4 (Post-Graduate)** down to **Grade 5.2 (CEFR B1 Accessible)**.
   - Extracts an actionable **Step-by-Step Checklist** and decodes domain jargon into plain 5th-grade definitions.
2. **Bionic / Dyslexia-Friendly Typography Studio:**
   - Applies **weighted word-initial fixation bolding** (highlighting the leading 45% of each word) alongside toggleable **syllable spacing** (`an·ti·co·ag·u·lant`), expanded letter/line spacing, an active line-focus ruler, and **3 WCAG AAA contrast palettes** (`15.8:1 Dark Slate`, `13.4:1 Warm Cream Paper`, `19.6:1 High-Contrast Yellow-on-Black`).
3. **Screen-Reader & ARIA Semantic Tree Repair (`wcag_auditor.py` + Live Browser Auditor):**
   - Automatically detects and repairs missing `<main>` landmarks, skipped heading hierarchies (`<h1>` $\rightarrow$ `<h4>`), low-contrast hex pairs (computing exact sRGB relative luminance $L = 0.2126R + 0.7152G + 0.0722B$ and contrast ratio $(L_1+0.05)/(L_2+0.05)$), missing `alt` attributes, unlabeled `<input>` controls, and ambiguous `"click here"` links.
   - Outputs **100% Repaired WCAG 2.2 AA HTML** + **Live Web Speech API Voice Narration** with adjustable cadence (`0.85x–1.25x`).
4. **Visual Concept Map (Interactive SVG Flowchart):**
   - Converts dense procedural text into an interactive step-by-step **SVG Decision Tree** for visual thinkers.
